# What's this about?

I wanted to do a review of the current agent orchestration frameworks, and I was thinking about using DX (developer experience) as the metric to do so. I use DX to specifically refer to a developer's experience using a particular tool, like a library or framework.

How do you measure DX? A framework called CDN (cognitive dimensions of notations) was introduced by Thomas Green to evaluate the "usability of information-based artefacts". I plan to apply the CDN framework to agent orchestration frameworks, following a methodological approach faintly similar to the one discussed in this paper: [Quantifying usability of domain-specific languages: An empirical study on software maintenance](https://www.sciencedirect.com/science/article/pii/S0164121214002799)
