# What's this about?

We can get very far with only a faint idea of how the internet works. Wifi this, router that, URLs and Domains, and using HTTP with HTML... are all concepts that we feel confident about, but we surprisingly know very litte about.

In my last work experience, I had to deal with the basics of Virtual Networks and firewalls (and what a VPN really means), which made me realize how important networking can be.

So, I'm taking a networking course (CSC387) with Professor Erfan as an attempt to better deal with networks.
